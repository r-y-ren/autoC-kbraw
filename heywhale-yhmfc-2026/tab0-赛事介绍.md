# Tab: 赛事介绍

## 1. 项目背景与目标

### 1.1 项目背景

为深入贯彻落实《国务院关于深入实施 “人工智能 +” 行动的意见》（国发〔2025〕11 号）及四川省气象局、省网信办关于贯彻《人工智能气象应用服务办法》的通知精神，结合雅安市 “数据要素 ×” 重点工作方案（2025—2026 年），并紧扣川西南（雅安）暴雨实验室实体化运行方案（2024-2027 年） 核心任务要求，推动气象预报技术创新发展，探索人工智能在复杂地形区短期降水预报中的应用潜力，特举办：

> **“青衣问天·雅雨先知”——首届雅安人机气象预报挑战赛（Ya’an Human-Machine Forecasting Challenge, YHMFC 2026）**

雅安素有“天漏”之称，地处四川盆地西缘，地形复杂、海拔落差大，年均降雨日数超200天，降水时空分布极不均匀，是检验短期降水预报能力的天然“试金石”。在此背景下，开展人机对抗式智能预报竞赛，具有突出的科学价值和业务示范意义。

本届赛事将首次采用“**雅安降水技能指数**”（**Ya’an Precipitation Skill Index, YPSI**）作为核心评分标准。该指数专为复杂地形区极端降水预报设计。

### 1.2 项目目标

| 目标类型     | 具体内容                                                                 |
|--------------|--------------------------------------------------------------------------|
| **技术目标** | 激发科研团队创新能力，研发优于现有人工预报的短期降水预报算法模型，显著提升雅安地区降水预报准确率与时空合理性。 |
| **业务目标** | 探索“AI+气象”的业务化路径，发掘具备实用价值的优秀算法模型，并推动优胜模型在雅安市气象局业务系统中试用与集成，提升防灾减灾服务能力。 |
| **品牌目标** | 打造全国气象行业内具有影响力的“人机对抗”品牌赛事，树立雅安市气象局“科技引领、创新驱动”的行业形象。 |

## 2. 竞赛名称、时间与地点

| 项目         | 内容                                                                                   |
|--------------|----------------------------------------------------------------------------------------|
| **竞赛名称** | 主标题：**“青衣问天·雅雨先知”——首届雅安人机气象预报挑战赛（YHMFC 2026）**
副标题：**青衣江畔，智掌天机——在雨落下之前，谁报的更准？** |
| **竞赛时间** | **2026年5月1日 – 2026年9月30日**（预报执行期）
• 发榜招募：2026年2月1日 – 3月31日（发布公告；开启报名；审核资质 + 发放历史数据包）
• 赛前准备：2026年4月1日 – 4月30日（组织YPSI培训与演练；签署协议）
• 正式竞赛：2026年5月至9月期间，每月组织2–4次，累计15–20次不定期测试（最终成绩由这15-20次不定期测试成绩来计算）
• 成绩评定与颁奖：2026年10月 |
| **竞赛地点** | 线上竞赛（参赛团队远程参与）
**主办单位**：四川省雅安市气象局                       |

## 3. 组织架构

| 角色               | 单位/说明                                                                 |
|--------------------|---------------------------------------------------------------------------|
| **主办单位**       | 雅安市气象局（雅安市气象学会）、川西南（雅安）暴雨实验室                                                              |
| **联合主办单位**   | 青藏高原气象研究院、雅安市科技局、雅安市自然资源和规划局、雅安市林业局                            |
| **技术支持单位**   | 上海和今信息科技有限公司（提供算力支持或平台服务）、宜宾市气象局（提供数据支持）                                |
| **竞赛组委会**     | 由主办及联合单位负责人组成，负责赛事总体策划、组织协调与资源统筹          |
| **专家评审委员会** | 由气象学、人工智能、数据科学等领域权威专家（含第三方独立专家）组成，负责：
• YPSI评分规则解释
• 争议仲裁
• 极端事件Δ项合规性审核
• 模型复现验证监督 |

## 4. 参赛对象与要求

| 项目         | 要求                                                                                                                               |
|--------------|------------------------------------------------------------------------------------------------------------------------------------|
| **参赛对象** | 全国高校、科研院所、企业及其他社会团体、个人均可参赛。团队负责人及成员须在发榜后完成注册。                                         |
| **团队要求** | • **机器团队**：每支队伍不限人数，需指定1名队长，可单人参赛。
• **人类团队**：每队≤3人（允许1–2名非本地专家外援，允许单人参赛），**至少1名雅安市气象局在职预报员**。
• **每人仅限参加一支队伍（单阵营）**。 |
| **报名方式** | 通过官方平台线上报名，不收取任何报名费用，签署《参赛协议》《数据使用保密协议》《知识产权预协议》。                                                     |

> **人类团队特别说明**：
> 人类团队作为“业务能力基准线”，不参与机器团队的评奖排名，但整体的能力影响机器团队的奖励额度（详见5.4节）。
