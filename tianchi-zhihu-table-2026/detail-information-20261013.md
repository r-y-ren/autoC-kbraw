## 赛题（一）：赛题与数据（Description & Data）

### 赛题背景

在许多实际应用场景中，如学术论文、金融报表、研究报告等，表格数据往往以非结构化的形式存在，例如图片或 PDF 文档。这些表格可能包含复杂的结构，如多级表头、合并单元格、跨页表格等。参赛选手需要开发出能够精确识别这些复杂表格结构的模型或算法，并将它们转换为结构化的电子表格格式（如 Excel）。这一过程不仅需要识别表格的行列结构，还需要准确提取单元格中的内容，包括文本、数字和特殊符号等。

### 赛题任务

参赛选手需要开发出能够精确识别这些复杂表格结构的模型或算法，实现从图片或 PDF 文档中提取表格，并将其转换为结构化的电子表格格式（如 Excel）。赛题包含三类问题：

1. **表格结构恢复（structure）**：将表格图像恢复为结构化的数据格式（如 HTML、Markdown、JSON 等），需要准确识别表格的行列结构、合并单元格（rowspan/colspan）等属性。提交格式为 JSON：
   - `row_count`：表格总行数
   - `col_count`：表格总列数
   - `cells`：非空单元格列表，每个单元包含 `row`（行索引）、`col`（列索引）、`row_span`、`col_span`、`text`（单元格文本）
2. **表格内容提取（extract）**：根据自然语言问题从表格中提取特定单元格或区域内容。
3. **表格内容推理（thinking）**：基于表格内容进行数值计算与逻辑推理，如加总、求差、比例计算、条件筛选、排序、格式归一等。

表格来源：财务报表、销售报告、采购对账单、质检报告、物流结算单、统计公报等。表格复杂性包括：跨页表格、合并单元格、多级表头、弱边框线、页眉页脚干扰、脚注混入、旋转扫描、单位变化、字段继承。

### 数据说明

数据目录包含：存放图片/PDF 的文件目录，以及记录问题的 `tests.xlsx` 文件。`tests.xlsx` 包含以下字段：

- `id`：问题唯一标识
- `file_name`：对应文件名（图片/PDF）
- `question_type`：问题类型（structure / extract / thinking）
- `question`：自然语言问题（structure 类型为固定指令）
- `table_hint`：表格定位提示（可帮助在多表格文档中定位目标表格）
- `answer_format`：答案格式要求说明

### 提交格式

提交文件为 `submission.xlsx`，包含 `id` 与 `answer` 两列，每个问题一行：

- structure 类型：`answer` 为符合上述 JSON 结构定义的字符串（需可被标准 JSON 解析器解析）
- extract 类型：`answer` 为提取的文本内容（与原文完全一致）
- thinking 类型：`answer` 为计算结果字符串（数值或文本，格式遵循 `answer_format` 要求）
- 无法回答的问题：`answer` 置为空字符串

### 评分方式

- 自动评分：最终得分 = 正确回答的问题数 / 总问题数 × 100，保留一位小数，满分 100 分
- 每道题独立判分，答案须与标准答案完全匹配（structure 题按 JSON 结构比对，extract/thinking 题按文本比对）
- 官方注明"待定"事项：单份文件处理时长上限、单道题推理成本上限、提交文件大小限制、每日提交次数、测评失败是否扣除提交次数——均以官方后续说明为准
