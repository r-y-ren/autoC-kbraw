| **2\. Writeup Completeness** | Features readable markdown, embedded visuals, and an attached **Public Kaggle Notebook**. | `[PASS/FAIL]` 

<br>

> All Writeups are evaluated on the following four components, where 0 is the lowest and 10 is the highest.

| Component | Evaluation Questions |
| :--- | :--- |
| **Football Score (30%)** | <ul><li>Would NFL teams (or the league office) be able to use these results on a week-to-week basis?</li><li>Does the analysis account for variables that make football data complex?</li><li>Are the ideas unique?</li></ul> |
| **Data Science Score (30%)** | <ul><li>Is the work correct?</li><li>Are claims backed up by data?</li><li>Are the statistical models appropriate given the data?</li><li>Are the analytical applications innovative?</li></ul> |
| **Writeup Score (20%)** | <ul><li>Is the Writeup well-written?</li><li>Is the Writeup easy to follow?</li><li>Is the motivation (metric, player evaluation, etc) clearly defined?</li></ul> |
| **Data Visualization Score (20%)** | <ul><li>Are the charts and tables provided accessible?</li><li>Are the charts and tables accurate?</li><li>Are the charts and tables innovative?</li></ul> |

<br>

> Participants are encouraged to show statistical code if it helps readers better understand their analyses. However, most code should be hidden in an Appendix. Any Writeup that doesn’t use the player tracking data will not be scored.
